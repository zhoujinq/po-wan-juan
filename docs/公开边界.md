# 公开边界与脱敏说明

## 可以公开

- `po-wan-juan/SKILL.md`：通用工作流程与安全边界。
- `po-wan-juan/references/`：分载体阅读流程、阅读卡片模板、知识地图访谈与模板、空白数据模板、阅读评分与反馈方法。
- `po-wan-juan/scripts/`：本地初始化、归档去重、周计算、字数校验和 Windows 提醒脚本。
- `index.html`：产品说明与可交互的虚构演示。
- `README.md`、`CHANGELOG.md`、`docs/`、`tests/`：复现、边界与验收材料。

## 绝不随本仓库公开

- 真实微信聊天记录、文章收藏、私人图片与视频、个人感悟原文。
- `inbox/`、`profile/`、`daily/`、`notes/`、`weekly/`、`memory/`、`state/`、`runtime/` 中的真实数据。
- 个人档案、好坏反馈评测集、修订记录、本地数据目录、账号标识和访问令牌。

个人数据目录必须放在仓库之外。公开网站没有提交、上传或保存私人内容的接口。

## 演示数据处理

- 首屏明确标注“页面数据均为虚构示例”。
- 原始投喂、每日洞察、个人档案和评分均为虚构内容，不对应真实个人记录。
- 页面出现的课程与文章链接是公开方法来源，不是用户私人收藏或知识库导出。
- `po-wan-juan/references/knowledge-map-example.md` 是虚构示例，只演示格式，不对应任何真实用户。
- 网站移除了外部字体服务，运行时不依赖飞书、妙搭、账号授权或第三方脚本。

## 公开前检查

1. 对源文件执行私密标识与本机路径扫描。
2. 运行 `tests/test_public_site.py`，阻断私密标识、外部运行依赖和失效页内锚点。
3. 核对技能文件与已验收版本的差异，避免误覆盖未同步改动。
4. 扫描技能目录，确认不含内部里程碑代号、内部文件引用或私人称呼（`tests/test_public_site.py`）。
5. 在私有仓库阶段先推送公开候选文件并验收；通过后再转为公开并启用 Pages。
