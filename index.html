实验 (2)：Deeper Research

蒋炎岩 / 原文

不是把整篇文章压成结论，而是说明它为什么与此刻的你有关：你正需要一个方法，把更多计算投入变成更可靠的判断。

约 20 分钟

读完只写三句：
我赞同什么？我反对什么？我接下来怎么做？

三次实验，
长成一条阅读闭环。

破万卷借用的是方法，不复刻实验作业：个人数据库让成长可见，深度研究让结论可检查，自我蒸馏让纠偏可回放。以下来源均为公开课程实验页面。

实验 (1)
会成长的个人助手

个人资料、成功流程与纠正都应进入可阅读、可修改的长期记忆，并能定位原文。

在破万卷里：原始投喂、个人档案、阅读索引与修订记录全部落盘。

实验 (2)
Deeper Research

先广泛探索，再深入有希望的方向；用检查、证据和修改，把更多投入换成更好结果。

在破万卷里：每天先扫全部再深读少数，加入反证复核与停止条件。

实验 (3)
蒸馏你自己

持续积累代表好与坏的反馈，形成评测集，再让行为偏好与输出对齐。

在破万卷里：好评、差评、适用范围与新旧规则对照都有据可查。

克制，也是能力。

一个长期接触私人记录的 Agent，最重要的不是“知道很多”，而是知道哪些事不能做、哪些话不能说满。

不假装读过

链接失效、需要登录、只有二手摘要时，明确标记“未读全文”或“仅摘要”。

不擅自行动

不自动发消息、点赞、关注或回复聊天对象；每晚仍由你亲自粘贴。

不滥用人格标签

不从一时情绪推断稳定人格，不根据聊天记录推断敏感属性。

不静默改变你

核心偏好先给差异，再由你确认；候选记忆与已确认档案分开。

从一次蒸馏开始。

  1. 装入 Skill

    从 GitHub 仓库下载完整的 po-wan-juan 文件夹，放入 Agent 的用户技能目录，保持 scripts/ 与 references/ 同级。

  2. 完成两轮访谈

    先确认目标与现实约束，再用代表作和好坏答案校准；不必一次写完美自我介绍。

  3. 确认提醒，今晚开始

    Windows 默认每天 22:00 弹窗；每周日 22:15 生成周总结。任务只在真实创建成功后算数。

把这句话交给你的 Agent

使用破万卷，开始蒸馏我。请先分两轮询问我的 90 天目标、长期主题、现实瓶颈、代表性文字和好坏反馈，再引导我确认本地数据目录、每天 22:00 的 Windows 提醒与每周日 22:15 的周总结。不要在我确认前修改长期偏好或创建系统任务。

查看 Skill 文件

Skill 不自动读取微信；文章与视频能否深读取决于宿主可用的浏览和解析能力。电脑关机时 22:00 无法弹窗，Windows 会在条件允许时补跑。其他系统可使用宿主已有的定时能力。

每日脚本只依赖 Python 标准库；没有 Python 也能按模板手工维护。提醒脚本支持预览与卸载，卸载不会删除个人数据。
