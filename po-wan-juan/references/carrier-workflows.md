# 分载体单篇阅读流程

## 通用拆条与核验

1. 微信自聊 TXT 先保留原件，只读解析；按 URL、空行和时间戳拆条。链接各自分配 ID，时间戳后的本人文字另作随笔，不把容器文件名当作内容事实。
2. 打开来源后判定纯文、图文、纯图片帖或视频。记录访问时间、真实可达性和实际读到的范围。
3. 先提主张与证据，再检查最强反例或另一种解释；不输出冗长隐式推理。

## 微信公众号纯文

1. 用宿主真实浏览器打开原 URL；浏览器不可用时才用合规抓取工具。不得绕过登录、验证码或 robots.txt。
2. 核对页面标题、作者/账号、正文起止；滚动或分页读到末尾，排除推荐、评论和转发语。
3. 按“小节标题 + 段落首句/短引文”保存证据定位。
4. 只有摘要、登录墙、失效或受限时标“仅摘要 / 未读全文 / 无法访问”，不借搜索摘要补正文。

## 微信公众号图文（正文 + 文中图）

1. 先按纯文流程读完整正文。
2. 枚举正文图片，按文中顺序编号；逐张打开原图或清晰渲染，读图内文字、图表、关键画面及其与相邻段落关系。
3. 证据写“第N图 + 相邻小节/段落 + 图片定位”；需要时保存到用户允许的本地证据目录并写绝对路径。
4. 逐图标已看/未看；任一张关键图未打开，标“未看画面”并列出图序号和原因，不得声称图文完整已读。

## 贴图 / 纯图片帖

1. 打开每张原图，保留顺序、相邻消息时间和上下文。
2. 读图内文字、版式、图表、手写或界面状态；图片间有连续关系时按顺序理解。
3. 证据写“图片N + 区域/图内短句 + 本地路径或URL”。
4. 模糊、缺图、加载失败时明确哪张哪区未看清，不脑补。

## B站视频

1. 打开视频原 URL，核对 BV 号、分P和时长；不以标题、简介、评论代替观看。
2. 优先取得官方字幕/CC；无字幕时用宿主真实可用的本地转写能力。保存逐字稿路径，记录每段起止时间戳与字幕短片段。
3. 依据内容转折选择关键画面，用宿主视频工具在明确时间点抽帧并实际打开查看；保存关键帧绝对路径和时间戳。
4. 对照稿件与画面，区分“讲述内容”和“画面证明的内容”，证据同时列两类定位。
5. 无稿标“未读声音/未读全文”，建议本机导出音频后转写；无帧标“未看画面”，建议本机取得视频文件后抽帧。两项缺一则不宣称完整验收。

## YouTube视频

1. 打开原 URL，核对视频 ID、版本、章节与时长。
2. 读取官方字幕或自动字幕并检查语言；必要时用本机可用转写补齐，保存带时间戳逐字稿。
3. 按章节与论点转折抽取关键帧并实际查看，保存路径和时间戳；不能用封面代替关键帧。
4. 交叉核对字幕和画面，尤其代码、图表、演示结果与口播不一致处。
5. 无稿/无帧分别标“未读声音/未读全文”“未看画面”，给出本机下载或用户提供文件后的转写、抽帧补救。

## 书 / 著作（PDF、EPUB或其他文件）

1. 真正打开文件，核对页数或导航结构、书名与版本；PDF优先读取页面文本，扫描页渲染后看；EPUB读取OPF/NCX/NAV和对应内容文档。
2. 先读目录，按用户范围或明确说明的抽读范围读完整章节。不要从目录推断章节内容。
3. PDF证据写“PDF第N页（文件页码）+ 章节/小节”；EPUB证据写“章节名 + 包内内容文档路径 + 小节/短引文”。
4. 卡片列“已读范围”和“未读范围”。全书未读完必须写“未读全文（全书）”；只有已实际读完的章节可写“全文已读（该章）”。
5. 图表或版式承载关键论证时同步看页面渲染；无法解析时标限制，不用同类书常识补齐。

## 本人感悟、随笔、认知或学习记录

1. 保留消息时间和原话定位，按一条或一个连续时间段归档。
2. 区分“当时想法 / 情绪表达 / 行动意图 / 长期原则候选”；只有用户确认后才升级为长期原则。
3. 一句话主张用中性概括，关键证据指向时间和短引文；不诊断人格，不推断健康、政治、宗教等敏感属性。
4. 私人职业想法只可留在获授权的本地阅读卡片，不写入示范地图、通用skill或公开说明。

## 微信自聊混合记录

1. 原件只读，先建立条目清单；每个URL独立一条，随笔按时间戳拆条。
2. 文件名提到某载体不等于正文存在该样本；以正文实际链接和附件为准。
3. 每个链接调用对应流程，每段随笔调用随笔流程，分别出卡；无法访问的链接仍保留卡片。
4. 用户把「每日输入」交来并要求出卡＋日摘时，按 `SKILL.md` 的「一次批量处理的要点」逐条处理，仍不装提醒、不装插件、不连 Notion。
