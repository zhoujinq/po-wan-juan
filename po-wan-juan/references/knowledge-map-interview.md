# 两轮知识地图访谈（可选步骤）

## 这是可选步骤

- **访谈不是阅读或日报的前置条件。** 只有用户明确说「开始 / 初始化 / 重建 / 修订知识地图」时，才读本文件发起访谈。
- 用户没提地图，就不发起、不追问、不等待、不暗示「先访谈效果更好」，也不为了后续测试向用户要地图。单篇阅读和「每日输入」的一次出卡＋日摘照常进行。
- 已有已确认或待确认的 `profile/knowledge-map.md` 时直接用地图；只有用户要求修订时才回到本文件。
- 用户中途停下，访谈就停，已答内容留在待确认区；停了不影响任何阅读。

## 推进方式

一次只推进一轮；每轮最多五组，允许只答知道的部分。

## 第一轮：画知识边界

先说明：“我想知道你已经会什么、正在学什么、哪里暂不碰，而不是给你贴兴趣标签。”

1. **已掌握**：哪些领域你能独立解释、操作或判断？各举一个作品、决定或解决过的问题作为证据；哪些只是听过名词？
2. **正在学与暂不碰**：未来90天正在补哪1—3块？每块怎样算完成？哪些领域明确不懂或现在不投入？
3. **目标与瓶颈**：90天最重要的1—3个结果是什么？时间、基础、信息质量、实践机会或反馈中，现实瓶颈是什么？每周可留多少亲读时间？
4. **信息源**：常用的一手资料、作者、社区、课程、书和内部材料有哪些？哪些来源你只作线索、不作结论？
5. **隐私红线**：哪些目录、聊天、账号、人物、公司或求职材料不能读、不能引用、不能进入公开说明？哪些推断永远不要做？

第一轮后先回放边界：“已掌握 / 正在学 / 暂不碰 / 90天目标 / 瓶颈 / 信息源 / 红线”。只把用户原话和可核对事实写入对应栏；Agent 的联想放待确认区。

## 第二轮：用代表性材料校准表达

说明：“这一轮不做性格测试，只校准什么样的阅读和判断对你有用。”

1. 给一段你本人写、且认为“像我”的文字；指出其中能代表你的句子及适用场景。
2. 给一个满意的阅读回答：好在哪里，是结论、证据、取舍还是表达方式？
3. 给一个不满意的回答：具体哪句不好，为什么，怎样改更好？
4. 对“深读 / 留档 / 略过”各给一个真实或假想例子，说明你的取舍标准。
5. 哪些话永远不要出现？第二轮是否有新增隐私红线或禁止推断？

没有代表作时不强迫提供。把好评、差评、适用范围和来源保存到评测集；一次任务的要求不能自动升级为永久偏好。

## 确认与修订

- 向用户展示 `profile/knowledge-map.md` 全稿，标出待确认条目；用户逐条确认或整体确认后记录日期。
- 每次修订保留旧版、原因、来源和日期到 `profile/revisions.jsonl`；可回滚，不覆盖历史。
- 新随笔只证明“当时的想法”，不能自动改成长期原则。相似反馈至少积累后再提出最小规则修订。
- 地图缺失不阻塞任何阅读：没有已确认或待确认地图时，单篇阅读和一次出卡＋日摘照常执行，卡片关系栏必须写“地图未就绪”，不得编造“与你何干”。
