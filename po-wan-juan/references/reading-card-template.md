# 阅读卡片模板

每次单篇阅读复制以下字段，缺一不可。证据须能回到实际打开的来源；无法取得内容时明确写“无正文证据”。

```markdown
# 阅读卡片 · [条目ID]

- 条目 ID：
- 载体类型：
- 标题：
- 原文定位（URL / 文件路径 / 消息时间）：
- 阅读状态（全文已读 / 已看画面 / 仅摘要 / 未读全文 / 无法访问）：
- 一句话主张：
- 关键证据（指向段落、页码、章节、时间戳或关键帧）：
- 与知识地图的关系：
- 建议动作（深读 / 留档 / 略过）+ 一句理由：
- 留给用户的一个判断问题：
- 置信度与限制说明：
```

## 填写约束

- 没有已确认或待确认地图时，关系栏只写“地图未就绪”，不编造“与你何干”。有待确认地图时，不把种子写成已确认个性结论。
- 书的全书状态与章节状态分开：列出已读章节、页码或文件内定位；其余写“未读全文”。
- 图文逐图记录“已看/未看及原因”；纯图片帖看不清就写看不清。
- 视频在证据中同时列字幕时间戳与片段、关键帧时间戳与文件路径；缺一项就标对应未读/未看。
- 仅摘要或无法访问时，一句话主张不得伪装成原文主张；写无法概括及原因。
- 建议动作仍需保守：无法访问通常留档等待亲读，不凭标题判断价值。
